# C# Dice Game

A simple C# console application created as part of my A-Level Computer Science studies.

## How it Works
- The program simulates a dice roll using C#'s `Random` class.
- The player rolls against the computer to see who gets the highest score.
- Includes basic input validation using `Console.ReadLine()`.

## Core Concepts Used
- Conditional statements (`if / else`)
- Random number generation (`Random.Next()`)
- Basic console input/output (`Console.WriteLine`)

## How to Run
1. Clone or download the `Program.cs` file.
2. Open it in Visual Studio or VS Code.
3. Build and run the solution.

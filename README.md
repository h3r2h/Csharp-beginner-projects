# C# Beginner & A-Level Computer Science Portfolio

A collection of C# console applications built during my Year 12 A-Level Computer Science studies. This portfolio demonstrates foundational programming concepts, clean code structure, defensive input validation (`int.TryParse`), custom subroutines, and object-oriented practices.

---

## 📁 Projects Index

### 1. Dice Game (`/DiceGame`)
* **Description:** A simple console-based game where the user rolls a dice against the computer to compare scores.
* **Core Concepts:** `Random` generation, conditional logic (`if / else`), basic console input/output.

### 2. Number Guessing Game (`/NumberGuessingGame`)
* **Description:** An interactive guessing game where the computer picks a random number between 1 and 100, providing higher/lower hints until guessed correctly.
* **Core Concepts:** `while` loops, safe input parsing (`int.TryParse`), attempt counters, robust error handling.

### 3. Grade Calculator - Subroutines Practice (`/Subroutines_practice`)
* **Description:** A modular program designed to practice procedural programming, parameters, return values, and input validation bounds.
* **Core Concepts:** Modular subroutines (`static int`, `static string`), parameter passing, return statements, and range validation.
